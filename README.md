# Portafolio · Electrónica Analógica 3

Portafolio web de **David Perdomo Cardoso**, integrante del Equipo 6 de Electrónica Analógica 3 y responsable de la documentación de ingeniería y el seguimiento experimental, Programa de Ingeniería Electrónica, Universidad Surcolombiana.

🌐 **Sitio publicado:** https://u20222207915-blip.github.io/portafolio_analoga3/

Incluye seis proyectos con la PSoC 5LP (CY8CKIT-059): ADC con LDR y libro de guías de todos los grupos, concepción de una solución electrónica, póster divulgativo NFC, PMV de sensores DHT11 + YL-38, puente H rediseñado con hojas de datos y el módulo expansor de puente H V2.

**Mi aporte:** elaboración y estandarización de las bitácoras de avance y los informes finales de cada entrega (memorias de cálculo, parámetros de operación, contraste entre valores teóricos y medidos, y resolución de fallos).

**Equipo 6:** Daniel García Trujillo (líder) · Juan Camilo Monje Rivas · Horus Samuel Ordoñez Dussán · Juan David Iriarte Trilleras · David Perdomo Cardoso.

Diseño web original de Daniel García Trujillo. Sitio estático (HTML, CSS y JavaScript sin dependencias). Para verlo localmente, abre `index.html`.
